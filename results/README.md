# Results Directory

This directory stores quick benchmark outputs from `benchmarks/compare_indexes.py`.

- `benchmark_results.json`: structured machine-readable output.
- `benchmark_report.md`: markdown summary table.
- `v2_*.json`: adaptive v2 benchmark, dynamic, and schedule-ablation outputs.
- `v3_*.json`: self-sizing v3 benchmark and validation outputs.
- `v4_*.json`: analytic framework regret, ablation, sensitivity, and diagnosis outputs.
- `phase_index_benchmark.json`: local phase-index 2D+3D benchmark output.
- `phase_index_report.md`: local phase-index reviewer table and summary.

For full publication-style artifacts, see `publication/`.
