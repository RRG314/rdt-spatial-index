# Legacy Archive

This directory preserves older repository material that is still useful for
historical context, reproducibility comparison, or migration references.

## Contents

- `original_github/`
  - `RDT_src_for_dev.py`
  - `rdt_spatial_index_with_benchmark.py`
  - Original monolithic implementation snapshots from early GitHub history.
  - Not part of the recommended current API or benchmark workflow.

- `reports/`
  - Historical DOCX reports generated during development and validation.
  - Preserved as authored artifacts; canonical reproducible results are under
    `publication/`.

## Policy

- Archived files are preserved, not deleted.
- Active development targets the package in `rdt_spatial_index/`, tests in
  `tests/`, and benchmark/reproducibility pipelines in `benchmarks/` and
  `publication/`.
