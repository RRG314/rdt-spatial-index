# Experiments

This directory contains exploratory research modules and domain-specific
prototypes (physics, AMR, quantum, correlation studies).

## Status

- Preserved and maintained as experimental research code.
- Not part of the default package API stability guarantees.
- Not required for core install/test/benchmark workflows.

## Guidance

- Use core package modules in `rdt_spatial_index/` for production/reproducible
  benchmarking.
- Treat experiment scripts as hypotheses and references for future work.
